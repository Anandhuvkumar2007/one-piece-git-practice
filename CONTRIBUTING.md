# 🏴‍☠️ Contributing to One Piece Grand Line Logbook

Ahoy! We welcome all software pirates, revolutionaries, and developers to contribute to the Grand Line Logbook.

## 📜 How to Practice Contributing with Git

1. **Fork the Repository** on GitHub to your account.
2. **Clone your fork** to your local machine:
   ```bash
   git clone https://github.com/YOUR_USERNAME/one-piece-git-quest.git
   ```
3. **Create a Topic Branch**:
   ```bash
   git switch -c feature/add-law-pirates
   # or
   git switch -c fix/bounty-typo
   ```
4. **Make Your Changes**:
   - Add new crew members in `data/crew.json`
   - Enhance styles in `style.css`
   - Add features in `app.js`
5. **Commit Your Code** using conventional commits:
   ```bash
   git add .
   git commit -m "feat(crew): add Trafalgar Law and Heart Pirates"
   ```
6. **Push to Your Branch**:
   ```bash
   git push origin feature/add-law-pirates
   ```
7. **Open a Pull Request (PR)** on GitHub with a description of your changes!

---

## 💎 Suggested Practice Ideas

- Add a new pirate (e.g., Trafalgar Law, Eustass Kid, Shanks, Gol D. Roger) to `data/crew.json`.
- Add sound effects or visual flair to bounty cards.
- Add a new category or Marine rank filter.
