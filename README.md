---

## 🌟 Features

- 📜 **Interactive Wanted Posters**: Straw Hat crew member bounty posters with dynamic berry calculation and role tags.
- 🔍 **Real-Time Search & Role Filter**: Instant searching by pirate name, epithet, or origin, plus role chips (Captain, Swordsman, Cook, etc.).
- 🍎 **Devil Fruit Archive**: Catalog of Paramecia, Zoan, and Logia fruits with awakenings and user lore.
- 👥 **Recruit Pirate Modal**: Add new nakama to your fleet with custom bounties and dreams (persisted in `localStorage`).
- 🔊 **Web Audio Synthesizer**: Sound effects (gold coin chimes, recruit fanfares, clicks) built using the browser Web Audio API without external asset dependencies.
- 🗺️ **Built-in Git Quest Road Map**: Interactive timeline with instant one-click copyable Git commands.
- 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile browsers.

## 🚀 Quick Start (Running the App)

You don't need any complex build tools or `npm install` to get started!

### Option 1: Open directly in your browser
Simply double-click `index.html` or right-click and choose **Open with Browser (Chrome/Edge/Firefox)**.

### Option 2: Live Server (VS Code / Python)
If you have Python installed:
```bash
python -m http.server 8000
```
Then open `http://localhost:8000` in your browser.

## 📚 Learn Git & GitHub Step-by-Step

Check out our complete, beginner-friendly guide:
👉 **[Read GIT_PRACTICE_GUIDE.md](GIT_PRACTICE_GUIDE.md)**

### Key Learning Milestones:
1. **Island 1 (Foosha Village)**: `git init`, `git status`, `git add`, `git commit`
2. **Island 2 (Loguetown)**: `git log`, `git diff`, inspecting history
3. **Island 3 (Water 7)**: `git branch`, `git switch -c`, feature branches
4. **Island 4 (Marineford)**: `git merge`, solving merge conflicts
5. **Island 5 (Red Line)**: `git remote add origin`, `git push`, `git pull`
6. **Island 6 (Egghead)**: Pull Requests, Forking, and 100% Free Hosting via **GitHub Pages**
