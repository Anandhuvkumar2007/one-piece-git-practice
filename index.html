Grand Line Navigation: Master Git & GitHub

Embark on 6 pirate trials to master version control from East Blue to the New World. Follow each trial in your terminal!

1
⛵ Island 1: Foosha Village — Initializing Your Voyage
Initialize your local Git repository and create your first pirate log commit.
git init
git status
git add .
git commit -m "feat: set sail with Straw Hat crew roster"
2
🧭 Island 2: Loguetown — Checking Your Log Pose History
Inspect your commit history and see the differences in your code changes.
git log --oneline --graph --decorate
git diff
3
🌿 Island 3: Water 7 — Creating New Feature Branches
Create a separate branch to build an upgrade for your ship or add a new nakama.
git switch -c feature/sunny-coupe-de-burst
# Make edits to files...
git add .
git commit -m "feat: add Coupe de Burst emergency escape"
4
⚔️ Island 4: Marineford — Conquering Merge Conflicts
Merge your feature branch back into the main timeline and resolve any conflicting bounties.
git switch main
git merge feature/sunny-coupe-de-burst
5
🌐 Island 5: Red Line — Connecting to GitHub (Remote Den Den Mushi)
Link your local ship repository to GitHub and push your code to the cloud world.
git remote add origin https://github.com/YOUR_USERNAME/one-piece-git-quest.git
git branch -M main
git push -u origin main
6
🚀 Island 6: Egghead — Free Live Deployment with GitHub Pages
Publish your One Piece app live for the entire world to view through GitHub repository Settings > Pages!
# In your GitHub repo: Go to Settings -> Pages -> Source: Deploy from branch (main / root) -> Save!
